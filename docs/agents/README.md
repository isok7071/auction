# Agent Artifacts

These files are the vendor-agnostic record of Fordewind AI-assisted work. `AGENTS.md` is the operating manual. `HANDOFF.md` is the live stage pointer.

Human-facing product docs are Russian (`README.md` and the design spec). This directory stays English for agent handoff.

| File | Purpose |
| --- | --- |
| `HANDOFF.md` | Current stage, next step, files, commands, verification, risks. Harness and Docker are done; next vendor starts data model and import. |
| `TOOLING.md` | Canonical MCP and skills inventory for this project. |
| `DECISIONS.md` | Architecture and tooling decisions with rationale. |
| `AI_WORKFLOW.md` | Skills, MCP/tools, subagents, prompts, and verification evidence. |
| `FEATURE_CHECKLIST.md` | Product and harness requirement coverage. |

Related files outside this directory:

- `AGENTS.md` - active Laravel Boost and Fordewind rules.
- `Task.md` - source requirements.
- `.agents/` - portable skills, MCP templates, and original design notes.
- `docs/superpowers/specs/2026-09-11-fordewind-laravel-design.md` - approved design.
- `docs/superpowers/plans/2026-09-11-fordewind-implementation.md` - implementation plan.
