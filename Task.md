# Цель

Разработать небольшое веб-приложение на Laravel для попарного голосования за фотографии аукционных автомобилей и просмотра статистики голосования.

# Исходные данные

**Репозиторий с данными:** <https://gitlab.fdw.ru/ext/test_task>

В репозитории находятся JSON-файлы с описанием автомобилей и фотографии. Имя файла фотографии соответствует значению ключа Image в исходных данных.

# Функциональные требования

## Страница 1 — Голосование

- Клиентскую часть страницы реализовать с использованием jQuery.
- Отобразить выпадающий список всех доступных моделей автомобилей.
- После выбора модели отображать две разные случайные фотографии автомобилей этой модели.
- В рамках одного цикла голосования ранее показанные фотографии не должны повторяться до исчерпания доступного набора. После исчерпания набора допускается начать новый цикл.
- Пользователь должен иметь возможность выбрать одну из двух фотографий: «Левая нравится больше» или «Правая нравится больше».
- Голос должен сохраняться на сервере. После голосования следующая пара должна загружаться без полной перезагрузки страницы с использованием jQuery/AJAX.
- Реализовать увеличение фотографий с использованием jQuery ezPlus и режима Tints.

## Страница 2 — Статистика

- Клиентскую часть страницы реализовать с использованием Vue.js.
- Реализовать фильтры по модели автомобиля и диапазону годов выпуска («от» — «до»). Изменение фильтров и обновление результатов должны происходить без полной перезагрузки страницы.
- Вывести список автомобилей в виде таблицы или карточек. Для каждого автомобиля показать фотографию, основные данные из исходного JSON и количество полученных голосов.
- Вывод и обновление данных статистики реализовать средствами Vue.js.
- Отобразить общее количество голосов по автомобилям, соответствующим выбранным фильтрам.

# Технические требования

- PHP + Laravel. Использовать актуальную стабильную версию Laravel на момент выполнения задания.
- MySQL в качестве основной базы данных.
- Подготовить миграции и сидеры либо отдельную команду импорта для загрузки исходных данных из JSON. Способ импорта должен быть описан в README.
- Использовать Eloquent и стандартные механизмы Laravel. Структура приложения должна быть понятной и поддерживаемой; бизнес-логику не следует без необходимости концентрировать в контроллерах.
- Обязательно использовать обе технологии: jQuery — на странице голосования, Vue.js — на странице статистики. Смешивать jQuery и Vue.js внутри одного компонента или одной функциональной области не требуется.
- Интерфейс должен быть адаптивным и корректно работать как минимум на актуальных версиях основных desktop-браузеров.
- Приложение должно разворачиваться с помощью Docker Compose.
- Добавить README с инструкцией по запуску проекта, настройке окружения, миграциям/импорту данных и кратким описанием принятых технических решений.
- Код должен быть читаемым и поддерживаемым. Комментарии и документация нужны там, где они поясняют неочевидные решения; избыточно комментировать очевидный код не требуется.
