# Superpowers (vendored)

Skills from [obra/superpowers](https://github.com/obra/superpowers) v6.3.0, MIT License.

The skill folders live in `.agents/skills/` so Cursor, Claude, Codex, and other agents can load them from this repository. Codex also sees them through `.codex/skills/` (symlinks into `.agents/skills`).

Update later by copying a newer `skills/` tree from upstream. Do not treat Superpowers as a Composer or npm dependency.
